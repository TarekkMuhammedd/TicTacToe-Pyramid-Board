# TicTacToe-Pyramid-Board
Report on the Pyramid Game Code, by Tarek Muhammed Abdel-Hamid. It explains a console tic-tac-toe variant on a 3x5 pyramid-shaped board with blocked cells. Players can compete against a friend or a computer that makes random valid moves. It covers the Player and RandomPlayer classes, validation functions, game mechanics, and game modes Date: 9/8/24
